Data engineering · Patents

InsideSEP: Standards Essential Patents data pipeline

A pipeline that brings 700,000+ patent records from scattered sources into one clean, analysis-ready dataset.

The problem

Standards Essential Patent data sits with many standards bodies, in scanned PDFs, OCR output, CSV files and APIs. Each source has its own format, so none of it could be analysed together.

What I built

  • Wrote Python scripts for automated web scraping and data transformation across all sources
  • Handled collection, consolidation, cleaning, normalisation and standardisation of 700,000+ records
  • Built validation and error-correction steps: missing values, deduplication and false-positive reduction
  • Built Tableau dashboards so clients could explore the patent analytics visually

Outcome

Manual extraction time dropped, pipeline throughput went up, and clients received a reliable dataset and dashboards they could use for patent analytics.

  • Python
  • Web scraping
  • OCR data
  • REST APIs
  • Tableau

Automation · Large-scale data

SCORE exam: registration, centre allocation and admit cards for 40,000+ students

I handled the SCORE exam for the entire North region on my own, from registration to admit cards, at zero cost.

The problem

SCORE is an all-India exam. In the North region, 40,000+ student records were coming in from offline forms across many centres, with no single system to collect them, allocate exam centres, or deliver admit cards.

What I built

  • A portal where every centre could type in its offline forms, with all entries combined in one place
  • City-wise and region-wise allocation of exam centres for each student
  • Fully automated admit cards: a roll number and a PDF generated for every student
  • Python scripts using the Google Drive API and pandas to create a Drive link for each admit card, so every student could open theirs
  • Research and development on how to build all of this at zero cost and still keep it accessible to every student

Outcome

40,000+ records handled across the North region with no database and no cloud cost. I managed the whole project end to end on my own.

  • Python
  • Google Drive API
  • pandas
  • Google Apps Script
  • Google Sheets
  • PDF automation
